How to use Meekhouse Tracker

1. Editing finishes

Click any room → click Edit on a finish card. Fill in the selection, change status, and add image links.

2. Adding custom finishes

Inside a room click + Add Finish. You can add any extra items (e.g. wallpaper, special trim, etc.).

3. Google Drive images

  1. Upload photo to Google Drive (account: meekhouse11460@gmail.com recommended).
  2. Right-click → Share → set to “Anyone with the link”.
  3. Copy the link and paste it into the Image URLs box.
  4. The app automatically converts most Drive links so the image displays.

4. Saving your work permanently

This is a static GitHub Pages site. Changes live in your browser until you export:

  1. Click Export JSON — downloads an updated data.json.
  2. Replace the data.json file in this GitHub repository with the new one.
  3. Commit & push. Refresh the live site and your data is updated for everyone.

You can also keep a local copy and re-import anytime.

5. GitHub Pages

If the site isn’t live yet: Repo → Settings → Pages → Source: Deploy from a branch → Branch: main / root → Save.
